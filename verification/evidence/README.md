# Evidence index area

Gate-level indexes will link qualifying run directories, raw evidence locations, and independent verdicts.
No qualifying runs exist at scaffold creation. Large raw bags, videos, and model binaries stay outside
normal Git; record a stable retrievable location, size, hash, and relevant time interval for each item.

An index is a pointer, not the evidence itself. Confirm reviewer access before a review. Do not put
access tokens, signed download URLs that will expire, or private credentials into a public repository.
