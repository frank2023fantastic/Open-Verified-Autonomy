# Build logs and demonstrations

Publish a short build log when there is something concrete to explain: a goal, a measured result,
a failed test, or an important decision. Frank leads the English narration; both teammates contribute findings.

Each entry should identify the gate/task, tested commit, experiment mode, report/evidence links,
what happened, what failed, and the next experiment. Keep raw videos outside normal Git and link them here.
The first log should explain why verification is a first-class part of this robot architecture.
