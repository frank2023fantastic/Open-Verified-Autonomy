# First experiments to discuss

Status: NOT RUN. This is an exploratory planning note, not a frozen acceptance protocol.
No trial counts, durations, speeds, success thresholds or animal observations are invented.

## Start with questions

1. Does the cat voluntarily approach a stationary device?
2. Does a short, slow movement invite engagement or withdrawal?
3. Does interest recur across separate sessions?
4. Does a sphere need fewer human rescues than the available wheeled base?
5. What does the owner find useful, inconvenient or concerning?

## Suggested progression

| Step | Activity | Record |
| --- | --- | --- |
| Baseline | Learn the mature kit away from the cat; check its controls and stopping. | Actual hardware/software, procedure, observed stops and open issues. |
| Stationary introduction | With the owner present, place an intact device in a clear area and allow voluntary approach. | Approach/avoidance and context; do not infer emotion from detection alone. |
| Manual movement | Operator requests one short, low-speed movement, then pauses. | Cat and robot trajectories where observable, interventions and withdrawal. |
| Repeat observation | Revisit on separate sessions without forcing participation. | Each cat/session separately; preserve no-interest results. |
| Form comparison | If a suitable finished ball is available, compare against the base using documented conditions. | Floor, starting positions, motion settings, device differences, rescue count and limitations. |
| One software change | Add measured telemetry logging or another reversible bounded change. | Diff, rollback, repeat observation and teammate review. |

The first motion sequence is: observe → invite → pause → end.
End the interaction when the animal withdraws or the operator sees a reason to stop.
Do not trap or pursue the cat to obtain a successful-looking recording.
Owner-away use is not tested by this progression.

## Minimal learning record

- Date, session ID, operator, observer and device/configuration.
- Question and conditions agreed before the session.
- Tutorial/source version and actual commands or motion settings.
- Observed approach, pursuit, withdrawal, contact, jams and interventions.
- Source video/telemetry location, relevant timestamps and limitations.
- What happened differently from the expectation.
- Next change and reviewer comments.

Use factual descriptions such as “approached within the marked region” rather than
“was happy” unless an appropriate method supports that interpretation.
Camera coverage, clock alignment, occlusion and different device noise/motion can confound comparison.
Predefine the measurements and number of sessions for any later quantitative claim.

Use T07's learning log and T08's review, without claiming G0–G8 completion.
Existing tutorial stop-readiness checks apply before motion.
Formal capability or unattended-use claims need their own versioned criteria and evidence.
