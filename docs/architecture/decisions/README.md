# Architecture decisions

Create `ADR-NNNN-short-title.md` from [TEMPLATE](TEMPLATE.md) for decisions that affect interfaces,
hardware, motion protection, evidence semantics, or the project scope.
Start as PROPOSED. Record alternatives, supporting sources/measurements, reviewer, and date when accepted.
An accepted design decision is not a verified hardware result.

First decisions to record: chassis/stop path; compute/OS stack; MCU transport; target enrollment and
distance measurement; raw evidence storage; project license.
